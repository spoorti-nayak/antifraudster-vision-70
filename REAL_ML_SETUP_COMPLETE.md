## 🔧 Troubleshooting

### "Python ML API unavailable"
- Make sure `python api_server.py` is running
- Check that it's on port 8000
- Look for firewall blocking localhost connections

### "Model files not found"
- Run `python train_advanced.py` first
- Check that `trained_models/advanced/` exists

### "ModuleNotFoundError"
```bash
conda activate fraud_ml
pip install -r requirements.txt
```

### High Fraud Scores for Normal Transactions
- Models need more training data
- Add real transaction history
- Retrain with actual data instead of synthetic

### Low Fraud Scores for Obviously Fraudulent Transactions
- Check feature extraction in `analyze-transaction`
- Verify ML API is receiving correct features
- Review model thresholds
